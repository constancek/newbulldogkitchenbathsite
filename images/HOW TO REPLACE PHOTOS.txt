HOW TO REPLACE A PHOTO ON THE WEBSITE

Every photo on the site is in this folder, sorted by page
(home, promos, process-steps, bathrooms/showers, kitchens/cabinets, and so on).

1. Find the photo you want to change and note its file name,
   for example: home/home-slide-new-bath.webp

2. Delete it and put your new photo in the same folder with the SAME name.
   The ending can be .jpg, .png or .webp, for example: home-slide-new-bath.jpg

3. Run the build (npm run build), or ask Claude to rebuild.
   Your photo is resized if needed, turned into a WebP file and used everywhere
   the old one appeared.

Where the website copies live
- After the build, each photo is also in public/assets/img, in the same
  folder (for example public/assets/img/bathrooms/showers/). Those are made by
  the build, so always replace photos here in images/, not there.
- The logo, phone home-screen icon and Made in USA badge are in public/assets/img/brand.
  The small icons on the estimate form are in public/assets/img/form-icons.
  To change one of those, replace the file there with the same name and type.

Tips
- Wide (landscape) photos work best for sliders and banners.
- Use photos at least 1200 pixels wide so they look sharp.
- Keep only one file per name. If two files share a name
  (like home-slide-new-bath.jpg and home-slide-new-bath.webp) the build stops
  and tells you which one to delete.
- Do not edit or delete .converted.json. It remembers which photos are
  already converted.

Automatic option (drop folder)
- Run: npm run watch-photos  (or ask Claude to start it) and leave it running.
- Put a new photo in the "replace donot push" folder with the SAME name as the
  site photo, for example showers-card.jpg.
- Within a few seconds it is swapped into images/, the site is rebuilt and the
  change is pushed to GitHub. "replace donot push/replace-log.txt" says what
  happened. Photos with a name that does not match are skipped and listed there.
- The folder itself is never pushed.
